# Новые возможности Мини-CRM

## 📎 Кликабельные ссылки в комментариях

Все URL в комментариях автоматически становятся кликабельными ссылками:
- Поддерживаются протоколы `http://` и `https://`
- Ссылки открываются в новой вкладке
- Длинные URL автоматически сокращаются для отображения (но полная ссылка сохраняется)
- Работает во всех местах: карточка клиента, активности, напоминания

**Пример:**
```
Обсудили условия договора. Подробности на https://example.com/contract
```
Ссылка `https://example.com/contract` станет кликабельной.

## 🖼️ Прикрепление изображений

### Возможности:
- Прикрепление изображений к комментариям клиентов и активностей
- Поддержка форматов: JPG, PNG, GIF, WebP
- Максимальный размер: 5 МБ на файл
- Максимальное количество: 10 изображений на запись
- Автоматическое сжатие изображений (до 1200px по ширине, качество 80%)
- Изображения сохраняются в base64 в localStorage и JSON бэкапах

### Как использовать:
1. В форме клиента или активности найдите поле "Комментарий"
2. Нажмите кнопку "📷 Добавить"
3. Выберите одно или несколько изображений
4. Изображения отобразятся в виде миниатюр
5. Можно удалить изображение, наведя курсор и нажав "✕"

### Просмотр изображений:
- Клик на миниатюру открывает полноразмерное изображение
- Навигация стрелками ← → или кнопками
- Закрытие: клавиша Esc, клик вне изображения или кнопка "✕"
- Кнопка "⬇" для скачивания изображения

### Где отображаются:
- **Карточка клиента** — в разделе "Комментарий"
- **Список активностей** — под каждой активностью
- **История активностей клиента** — в карточке клиента
- **Модальное окно напоминания** — при звонке/встрече

## 💾 Хранение данных

### localStorage:
- Все данные (включая изображения) сохраняются в localStorage браузера
- Изображения хранятся в base64 формате
- Рекомендуется регулярно делать JSON бэкапы

### CSV:
- Текстовые данные синхронизируются с CSV файлом
- Изображения НЕ сохраняются в CSV (слишком большие для текстового формата)
- Используйте JSON бэкап для полного сохранения данных

### JSON бэкап:
- Кнопка "💾 JSON" в шапке создаёт полный бэкап
- Включает все данные: клиенты, активности, изображения
- Рекомендуется делать еженедельно
- Восстановление: кнопка "📥 JSON"

## ⚠️ Ограничения

1. **Размер localStorage**: браузеры ограничивают localStorage (~5-10 МБ)
   - При большом количестве изображений может потребоваться очистка
   - Регулярно делайте JSON бэкапы

2. **CSV синхронизация**: изображения не синхронизируются с CSV
   - CSV содержит только текстовые данные
   - Для полного бэкапа используйте JSON

3. **Производительность**: большое количество изображений может замедлить работу
   - Рекомендуется не более 100-200 изображений в базе
   - Изображения автоматически сжимаются

## 🔧 Технические детали

### Компоненты:
- `RichComment` — отображение текста с кликабельными ссылками и изображениями
- `RichCommentInput` — ввод комментария с возможностью прикрепления изображений
- `ImageInput` — компонент для прикрепления и управления изображениями
- `ImagePreview` — превью изображения с возможностью открытия галереи

### Функции:
- `parseTextWithLinks()` — парсинг текста и выделение URL
- `compressImage()` — сжатие изображений перед сохранением
- `openImageGallery()` — открытие полноразмерной галереи

### Типы данных:
```typescript
interface Client {
  // ... другие поля
  images: string[]; // массив base64 data URLs
}

interface Activity {
  // ... другие поля
  images: string[]; // массив base64 data URLs
}
```
