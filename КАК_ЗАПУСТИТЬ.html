📋 Мини-CRM

Инструкция по запуску программы

⚠️ Важно! Что нужно для запуска:

Google Chrome или Microsoft Edge (любой из них)

Другие браузеры (Firefox, Opera, Яндекс) не поддерживаются!

📥 Шаг 0: Скачайте браузер

🌐
Google Chrome
Скачать Chrome
🔷
Microsoft Edge
Скачать Edge
1

Найдите файл запуска

В папке с программой найдите файл Запустить-Мини-CRM.bat

📁 Это обычный файл с иконкой Windows

2

Запустите программу

🖱️ Дважды кликните по файлу Запустить-Мини-CRM.bat

Программа автоматически откроется в Chrome или Edge

3

Создайте базу данных

📄 В шапке программы нажмите кнопку "📄 Создать базу"

💾 Выберите место для файла (например, Документы)

✏️ Введите имя: crm_database.csv

✅ Нажмите "Сохранить"

4

Проверьте статус

В шапке должен появиться зелёный бейдж:

✅ crm_database.csv (14:32:05)

Это значит, что база данных подключена и работает!

5

Начните работу!

👥 Перейдите на вкладку "Клиенты"

➕ Нажмите "+ Новый клиент"

📝 Заполните данные и сохраните

🎉 Готово! Данные автоматически сохраняются в CSV-файл

✅ Всё готово!

Теперь вы можете:

  • Добавлять клиентов и контакты
  • Создавать активности (звонки, встречи)
  • Получать напоминания о звонках
  • Открывать CSV-файл в Excel для отчётов

🆘 Если что-то не работает:

Проблема: Файл не открывается

Решение: Установите Google Chrome или Microsoft Edge


Проблема: Кнопка "Создать базу" не работает

Решение: Обновите браузер до последней версии


Проблема: Белый экран или ошибка

Решение: Нажмите F12, посмотрите консоль, сделайте скриншот
