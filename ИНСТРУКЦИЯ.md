# Мини-CRM - Инструкция по установке и запуску

## 🚀 Быстрый старт (для Windows)

### Способ 1: Автоматический запуск (рекомендуется)

1. **Дважды кликните** по файлу `Запустить-Мини-CRM.bat`
2. Программа автоматически откроется в Chrome или Edge
3. Нажмите кнопку **"📄 Создать базу"** в шапке
4. Выберите место для файла базы данных (например, `crm_database.csv`)
5. Готово! Программа работает.

### Способ 2: Ручной запуск

1. Откройте папку `dist`
2. Найдите файл `index.html`
3. **Правой кнопкой мыши** → **"Открыть с помощью"** → **Google Chrome** или **Microsoft Edge**
4. Нажмите **"📄 Создать базу"** в шапке

## 📥 Что нужно скачать для запуска

### Обязательное:

**Google Chrome** или **Microsoft Edge** (любой из них)

- **Google Chrome**: https://www.google.com/chrome/
- **Microsoft Edge**: https://www.microsoft.com/edge

**Почему именно Chrome или Edge?**
- Только эти браузеры поддерживают File System Access API
- Это технология для работы с файлами на вашем компьютере
- Без неё программа не сможет синхронизироваться с CSV-файлом

### Не нужно:
- ❌ Интернет (программа работает офлайн)
- ❌ Серверы или базы данных
- ❌ Дополнительные библиотеки
- ❌ Node.js или другие инструменты

## 🔧 Если программа не запускается

### Проблема 1: "Файл не открывается"

**Решение:**
1. Убедитесь, что используете Chrome или Edge
2. Не используйте Internet Explorer или Firefox
3. Попробуйте запустить через `Запустить-Мини-CRM.bat`

### Проблема 2: "Белый экран" или "Ошибка загрузки"

**Решение:**
1. Нажмите F12 (откроется консоль разработчика)
2. Посмотрите на вкладку "Console"
3. Если видите ошибки - сделайте скриншот
4. Попробуйте очистить кэш: Ctrl + Shift + Delete

### Проблема 3: "Кнопка 'Создать базу' не работает"

**Решение:**
1. Убедитесь, что используете Chrome 86+ или Edge 86+
2. Обновите браузер до последней версии
3. Проверьте, что файл открыт через `file://` протокол (а не через сервер)

### Проблема 4: "Данные не сохраняются в CSV"

**Решение:**
1. Проверьте статус в шапке (должен быть зелёный ✅)
2. Убедитесь, что CSV-файл не открыт в Excel
3. Если файл занят - закройте Excel и нажмите "💾 Сохранить"

## 📋 Пошаговая инструкция

### Шаг 1: Установка браузера

1. Скачайте **Google Chrome** с https://www.google.com/chrome/
2. Установите браузер (просто нажимайте "Далее")
3. Перезагрузите компьютер (не обязательно, но рекомендуется)

### Шаг 2: Запуск программы

1. Найдите файл `Запустить-Мини-CRM.bat` в папке с программой
2. **Дважды кликните** по нему
3. Дождитесь открытия браузера

### Шаг 3: Создание базы данных

1. В шапке программы нажмите **"📄 Создать базу"**
2. Выберите папку для сохранения (например, `Документы`)
3. Введите имя файла: `crm_database.csv`
4. Нажмите **"Сохранить"**
5. В шапке появится зелёный бейдж: **"✅ crm_database.csv"**

### Шаг 4: Начало работы

1. Перейдите на вкладку **"👥 Клиенты"**
2. Нажмите **"+ Новый клиент"**
3. Заполните данные
4. Нажмите **"💾 Сохранить"**
5. Данные автоматически сохранятся в CSV-файл

## 🎯 Как проверить, что всё работает

### Проверка 1: Статус базы данных

В шапке должен быть зелёный бейдж:
```
✅ crm_database.csv (14:32:05)
```

Если видите:
- 🔌 База не подключена → нажмите "📄 Создать базу"
- ⚠️ Ручной режим → установите Chrome/Edge
- ❌ Ошибка → закройте Excel и нажмите "💾 Сохранить"

### Проверка 2: Сохранение данных

1. Добавьте клиента
2. Откройте CSV-файл в Блокноте
3. Вы должны увидеть данные клиента
4. Если данные есть → всё работает!

### Проверка 3: Открытие в Excel

1. Закройте программу (или убедитесь, что файл не редактируется)
2. Дважды кликните по `crm_database.csv`
3. Excel должен открыться с данными
4. Если данные отображаются → всё работает!

## 🆘 Часто задаваемые вопросы

### Q: Можно ли использовать Firefox?
**A:** Нет. Firefox не поддерживает File System Access API. Используйте Chrome или Edge.

### Q: Нужен ли интернет?
**A:** Нет. Программа работает полностью офлайн. Интернет нужен только для установки Chrome.

### Q: Где хранятся данные?
**A:** В двух местах:
1. CSV-файл (основное хранилище)
2. localStorage браузера (кэш для быстрого доступа)

### Q: Можно ли открыть CSV в Excel?
**A:** Да! CSV-файл открывается в Excel двойным кликом. Не редактируйте его, пока программа запущена.

### Q: Что делать, если программа зависла?
**A:** 
1. Закройте вкладку браузера
2. Запустите снова через `Запустить-Мини-CRM.bat`
3. Данные восстановятся из localStorage

### Q: Как сделать резервную копию?
**A:** Нажмите кнопку **"💾 JSON"** в шапке. Сохраните файл на флешку или в облако.
