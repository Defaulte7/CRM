# Мини-CRM — Инструкция по установке и использованию на Windows

## 🚀 Быстрый старт

### 1. Откройте файл в браузере
- Найдите файл `index.html` в папке `dist/`
- Дважды кликните по нему — он откроется в браузере по умолчанию
- **Рекомендуется**: Chrome или Microsoft Edge (для полной синхронизации с файлом)

### 2. Создайте базу данных
- В шапке нажмите **«📄 Создать базу»**
- Выберите папку и имя файла (например, `crm_database.csv`)
- Файл будет создан на вашем компьютере — это и есть ваша база данных

### 3. Работайте!
- Добавляйте клиентов, активности, заметки
- Все данные **автоматически сохраняются** в CSV-файл каждые 1.2 секунды
- Файл можно открыть в Excel в любой момент

### Двусторонняя синхронизация:
1. **Запись**: при любом изменении в CRM → данные записываются в CSV через 1.2 сек
2. **Чтение**: каждые 2 сек проверяется, не изменился ли файл извне (например, если вы отредактировали его в Excel)
3. **Кэш**: все данные также хранятся в localStorage для мгновенного доступа

## 🔧 Подробная настройка

### Рекомендуемый браузер: Google Chrome или Microsoft Edge
Оба браузера поддерживают **File System Access API** — технологию, позволяющую напрямую читать/писать файлы на диске.

### Как проверить поддержку:
- В шапке CRM должен быть зелёный бейдж **«✅ файл.csv (время)»**
- Если видите **«⚠️ Ручной режим»** — используйте Chrome/Edge

### Первый запуск:
1. Откройте `dist/index.html` в Chrome
2. Нажмите **«📄 Создать базу»**
3. Выберите место сохранения (например, `Документы/crm_database.csv`)
4. Готово! База создана и синхронизируется автоматически

## 📊 Статус синхронизации

В шапке отображается бейдж с текущим статусом:

| Иконка | Статус | Что означает |
|--------|--------|--------------|
| 🔌 | Не подключена | База не выбрана |
| ⏳ | Подключение | Идёт подключение к файлу |
| ✅ | Подключена | Всё работает, файл синхронизирован |
| 💾 | Синхронизация | Идёт запись данных в файл |
| 📖 | Чтение | Файл изменился, идёт чтение |
| ❌ | Ошибка | Проблема с файлом (обычно — занят Excel) |
| ⏳ | Ожидание | Есть несохранённые изменения |

### Если файл занят Excel:
- CRM покажет **«❌ Файл занят, повтор N/10...»**
- Система автоматически повторит запись через 5 секунд
- До 10 попыток — после этого данные сохранятся при закрытии Excel

## 💾 Резервное копирование

### Автоматическое:
- CSV-файл обновляется при каждом изменении
- localStorage хранит копию данных

### Ручное (рекомендуется еженедельно):
1. Нажмите **«💾 JSON»** в шапке
2. Сохраните файл `crm_backup_2024-XX-XX.json`
3. Храните на флешке или в облаке

### Восстановление из бэкапа:
- Нажмите **«📥 JSON»** и выберите файл бэкапа

---

## 📝 Работа с Excel

### Открытие CSV в Excel:
1. Закройте CRM (или убедитесь, что файл не редактируется)
2. Дважды кликните по `crm_database.csv`
3. Excel откроет файл с правильной кодировкой (UTF-8 с BOM)
4. Разделитель — точка с запятой (;)

### Редактирование в Excel:
- **НЕ РЕКОМЕНДУЕТСЯ** одновременно работать в CRM и Excel
- Если нужно отредактировать в Excel:
  1. Сохраните JSON-бэкап
  2. Откройте CSV в Excel
  3. Внесите изменения
  4. Сохраните CSV (Ctrl+S)
  5. В CRM нажмите **«🔄 Обновить»** — данные подтянутся

## ⚙️ Технические детали

### Формат CSV:
```csv
### КЛИЕНТЫ
ID;Наименование;Контакт;ИНН;КПП;ОГРН;Телефон;E-mail;Адрес;Сайт;Банковские реквизиты;Комментарий;Статус;Доп.контакты;Дата создания
abc123;ООО "Ромашка";Иванов И.И.;7701234567;770101001;1027700123456;+74951234567;info@romashka.ru;г. Москва, ул. Ленина, 1;www.romashka.ru;р/с 40702810...;Работаем с 2020 года;active;;2024-01-15T10:30:00.000Z

### АКТИВНОСТИ
ID;КлиентID;Дата;Время;Тип;Тема;Комментарий;Статус;Отложено до;Дата создания
def456;abc123;2024-10-15;14:30;call;Обсудить договор;Позвонить после обеда;planned;;2024-10-14T09:00:00.000Z
```

### Хранение изображений:
- Изображения сохраняются в **base64** внутри localStorage и JSON
- В CSV изображения **не сохраняются** (слишком большой размер)
- Используйте JSON-бэкап для полного сохранения

### Ограничения:
- localStorage: ~5-10 МБ (зависит от браузера)
- Рекомендуется не более 5000 записей
- Изображения: не более 100-200 штук

## 🐛 Решение проблем

### «База не подключена»
- Нажмите **«📄 Создать базу»** или **«📂 Открыть базу»**

### «Файл занят»
- Закройте Excel (или другую программу, работающую с файлом)
- CRM автоматически повторит запись

### Данные пропали
- Проверьте localStorage: откройте DevTools (F12) → Application → Local Storage
- Восстановите из JSON-бэкапа

### Не работает в Firefox/Safari
- Используйте ручной режим: **«⬇ CSV»** для сохранения, **«⬆ CSV»** для загрузки
- Или установите Chrome/Edge

### Медленная работа
- Удалите старые записи
- Очистите архив
- Уменьшите количество изображений

- Все данные хранятся **локально** на вашем компьютере
