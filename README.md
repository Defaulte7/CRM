# 📋 Мини-CRM

**Офлайн CRM-система для Windows с синхронизацией в CSV-файл**

![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-green)

## 🚀 Быстрый старт

### 1. Установите браузер
Скачайте **Google Chrome** или **Microsoft Edge**:
- 🌐 Chrome: https://www.google.com/chrome/
- 🔷 Edge: https://www.microsoft.com/edge

### 2. Запустите программу
Дважды кликните по файлу **`Запустить-Мини-CRM.bat`**

### 3. Создайте базу данных
Нажмите **"📄 Создать базу"** в шапке и выберите место для CSV-файла

### 4. Работайте!
Добавляйте клиентов, создавайте активности, получайте напоминания

## ✨ Возможности

### 👥 Управление клиентами
- Полная карточка клиента (реквизиты, контакты, адрес)
- Дополнительные контакты (неограниченно)
- Поиск по всем полям
- Архивирование и восстановление

### 📅 Активности и напоминания
- Типы: Звонок, Встреча, Письмо, Оплата, Документы
- Автоматические напоминания в назначенное время
- Системные уведомления браузера
- Отложенные задачи

### 💬 Rich-комментарии
- Кликабельные ссылки в тексте
- Прикрепление изображений
- Галерея с навигацией
- Сжатие изображений

### 🔄 Синхронизация с файлом
- **Автоматическая запись** каждые 1.2 секунды
- **Автоматическое чтение** каждые 2 секунды
- Двусторонняя синхронизация с CSV
- Обработка блокировок файла
- Визуальный статус синхронизации

### 💾 Резервное копирование
- JSON-экспорт полной базы данных
- CSV-экспорт для Excel
- Автоматическое сохранение в localStorage

## 📊 Формат данных

### CSV-файл (база данных)
```csv
### КЛИЕНТЫ
ID;Наименование;Контакт;ИНН;КПП;ОГРН;Телефон;E-mail;Адрес;Сайт;Банковские реквизиты;Комментарий;Статус;Доп.контакты;Дата создания
abc123;ООО "Ромашка";Иванов И.И.;7701234567;770101001;1027700123456;+74951234567;info@romashka.ru;г. Москва, ул. Ленина, 1;www.romashka.ru;р/с 40702810...;Работаем с 2020 года;active;;2024-01-15T10:30:00.000Z

### АКТИВНОСТИ
ID;КлиентID;Дата;Время;Тип;Тема;Комментарий;Статус;Отложено до;Дата создания
def456;abc123;2024-10-15;14:30;call;Обсудить договор;Позвонить после обеда;planned;;2024-10-14T09:00:00.000Z
```

**Особенности:**
- Кодировка: UTF-8 с BOM (открывается в Excel без проблем)
- Разделитель: точка с запятой (;)
- Изображения хранятся в base64 (только в JSON, не в CSV)

## 🐛 Решение проблем

### Программа не запускается
✅ Установите Chrome или Edge  
✅ Используйте файл `Запустить-Мини-CRM.bat`

### Кнопка "Создать базу" не работает
✅ Обновите браузер до последней версии  
✅ Проверьте, что файл открыт через `file://` протокол

### Данные не сохраняются в CSV
✅ Закройте Excel (файл может быть занят)  
✅ Нажмите "💾 Сохранить" принудительно  
✅ Проверьте статус в шапке (должен быть зелёный ✅)

### Белый экран или ошибка
✅ Нажмите F12, посмотрите консоль  
✅ Очистите кэш: Ctrl + Shift + Delete  
✅ Перезагрузите страницу: F5
