✅ ВАМ НУЖНО СКАЧАТЬ ТОЛЬКО ОДНО:

   🌐 Браузер Google Chrome ИЛИ Microsoft Edge
   
   Скачать Chrome:  https://www.google.com/chrome/
   Скачать Edge:    https://www.microsoft.com/edge

   (Оба браузера бесплатные, выбирайте любой)

📁 ГДЕ НАХОДИТСЯ ФАЙЛЫ ПРОГРАММЫ:

   После сборки все файлы находятся в папке:
   
   📂 dist/
      └── 📄 index.html  ← ЭТО И ЕСТЬ ВАША ПРОГРАММА!

═══════════════════════════════════════════════════════════════

🚀 КАК ЗАПУСТИТЬ (3 простых шага):

   1️⃣ Установите Chrome или Edge (если ещё не установлен)
   
   2️⃣ Откройте папку dist/
   
   3️⃣ Дважды кликните по файлу index.html
   
      → Программа откроется в браузере
      → Нажмите "📄 Создать базу" для создания файла базы данных
      → Готово! Можно работать

═══════════════════════════════════════════════════════════════

⚡ БЫСТРЫЙ ЗАПУСК (автоматически):

   Если у вас Windows, используйте файл:
   
   📄 Запустить-Мини-CRM.bat
   
   Этот файл автоматически:
   - Найдёт Chrome или Edge
   - Откроет программу в правильном браузере
   - Создаст базу данных

═══════════════════════════════════════════════════════════════

❓ ЕСЛИ НЕ РАБОТАЕТ:

   Проблема: "Файл не открывается"
   Решение: Убедитесь, что файл dist/index.html существует
   
   Проблема: "Открывается, но не работает"
   Решение: Откройте файл в Chrome или Edge (не в Firefox/Safari)
   
   Проблема: "Не могу найти папку dist"
   Решение: Папка dist создаётся автоматически после сборки проекта
            Если её нет, нужно выполнить команду: npm run build

═══════════════════════════════════════════════════════════════

💡 КАК ЭТО РАБОТАЕТ:

   dist/index.html — это ОДИН ФАЙЛ, который содержит:
   - Весь код программы
   - Все стили оформления
   - Все библиотеки (React, Tailwind CSS)
   
   Файл работает ПОЛНОСТЬЮ ОФЛАЙН — интернет не нужен!
   
   При первом запуске программа создаст файл базы данных
   (crm_database.csv) в выбранной вами папке. Этот файл
   можно открыть в Excel для просмотра и редактирования.

🆘 НУЖНА ПОМОЩЬ?

   1. Убедитесь, что у вас установлен Chrome или Edge
   2. Найдите файл dist/index.html
   3. Откройте его двойным кликом
   4. Если не работает — используйте файл Запустить-Мини-CRM.bat
